# sevenPad
A recreation of Windows 7's Notepad in Qt Quick

## About this project
**sevenPad** is an accurate-as-possible recreation of the Windows 7 Notepad Application. This uses Qt Quick, with a backend of C++, and was mainly developed in CLion. 

I made this to help provide accompanying software to [AeroThemePlasma](https://gitgud.io/aeroshell/atp/aerothemeplasma), which is a really cool theme that helps make KDE look like Windows 7.
